# Наше меню

Приложение для телефона: короткая анкета → меню на неделю под ваш бюджет с учётом **актуальных скидок**
чешских магазинов (Lidl, Kaufland, Albert, Tesco, BILLA, Penny, Globus, COOP…) → список покупок в граммах.

- Анкета: магазины, сколько человек, дни и приёмы пищи, техника на кухне, тип питания, что не едим, что есть дома, бюджет.
- Меню подбирается автоматически: дешевле — то, что сейчас по акции; продукты переиспользуются между блюдами.
- Любое блюдо можно заменить — видно, на сколько станет дешевле или дороже.
- Список покупок: сколько нужно, сколько упаковок взять, в каком магазине акция, до какого числа, нужна ли карта.
- «Где дешевле купить всё сразу?» — сравнение корзины по магазинам.

## Файлы

- `data/recipes.json` — рецепты (граммы на одну взрослую порцию).
- `data/catalog.json` — продукты: размер упаковки, примерная обычная цена, слова для поиска скидок.
- `scripts/update_prices.py` — собирает скидки с kupi.cz в `prices.json` (GitHub запускает его каждое утро).

## Сайт

Приложение лежит на GitHub Pages. Цены обновляет GitHub Actions («Обновить цены и скидки»),
вручную: вкладка **Actions → Обновить цены и скидки → Run workflow**.

## Установка на Android

Откройте адрес сайта в Chrome → ⋮ → **Установить приложение** (или «Добавить на главный экран»).

Ответы анкеты, меню и отметки хранятся на самом телефоне.

## Запуск на компьютере

```
python -m http.server 8000
```
и откройте http://localhost:8000. Обновить цены локально: `python scripts/update_prices.py`.
